# Skimr UI audit 001, 2026-11-14

Scope: `app/page.tsx`, `app/layout.tsx`, `app/globals.css`, plus how the page displays what the route returns.
Mode: AFTER. Nothing below has been changed. Approve numbers and I fix those only.

Gate items already fixed during the build: headline link hover/focus affordance (R-39), missing `footer` landmark (R-39), inactive tab hover state (R-39).

## Findings

1. **MEDIUM, R-38.** The verdict is formed from the first 15,000 characters, but `word_count` and the read time are computed from the full extracted text. On a long page that reads "from 258,141 words, 1,174 min read" for a verdict the model formed from roughly 5 percent of it. Fix: compute both from the same truncated text.

2. **LOW, R-27.** No idle state in the results area: before the first run the region is simply empty. Fix: one muted line, "Paste a link above and the receipts appear here."

3. **LOW, R-20.** Favicon is still the Next.js default. Fix: a paper-coloured two-letter mark, or drop it rather than ship someone else's.

4. **LOW, R-39.** The dateline is computed once at module load and rendered under `suppressHydrationWarning`, so a tab left open past midnight shows yesterday's date. Fix: recompute on mount.

5. **LOW, R-39.** The "✓ VERIFIED" label abbreviates with a glyph only; it is text-adjacent so it reads fine, but a screen reader announces "check mark verified". Fix: `aria-hidden` on the glyph, or drop the glyph.

6. **LOW, R-40.** Quote length is not capped, so a model that returns a whole paragraph as its quote produces a very tall entry. Fix: cap displayed quotes at about 400 characters with an ellipsis, and mark the fact as truncated rather than verified? No: truncating a verified quote misrepresents it. Leave as is if you prefer honesty over tidiness.

## Not findings

- Zero border radius everywhere, no motion, single accent, one column: deliberate newsprint direction, not a default.
- The em dash in `lib/verify.test.ts` is article fixture text, needed to test dash normalization.
- No dark mode: light-only was requested.
